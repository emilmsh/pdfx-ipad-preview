# pdfx-ipad-preview

Throwaway host for a build of [PDF Scholar](https://github.com/emilmsh/pdf-scholar),
used to answer one question: what does an iPad actually give us?

Not a release, not a product, not maintained. Published by
`scripts/publish-preview.mjs` in that repository.

- `/` — the app (browser target: reads PDFs, annotates, exports; no in-place save)
- `/probe.html` — platform diagnostics, reports what the device supports

Delete this repository once the spike has answered. Nothing depends on it.
